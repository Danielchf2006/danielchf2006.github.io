# Fonts

**Monocraft.woff2** — a Minecraft-style pixel font by Idrees Hassan, licensed
under the SIL Open Font License 1.1 (see `LICENSE-Monocraft.txt`). Converted from
the upstream `.ttf` release (v4.2.1) to woff2.

Used **only** for text that is mid-glitch — the `.px` class in
`src/styles/global.css`, applied transiently by `src/scripts/glitch.ts` and by
`GlitchText.astro`'s reveal. Resting body copy never uses it.

Source: https://github.com/IdreesInc/Monocraft
