# Fonts

All served from `/fonts/…` and declared with `@font-face` in
`src/styles/global.css`.

| File | Family | Role | License |
|---|---|---|---|
| `NeueBit-Regular.woff2`, `NeueBit-Bold.woff2` | NeueBit | body text (`--font-sans`) | PP® "free to try" — free for personal / portfolio use |
| `Mondwest-Regular.woff2`, `Mondwest-Bold.woff2` | Mondwest | headings (`--font-display`) | PP® "free to try" — free for personal / portfolio use |
| `Monocraft.woff2` | Monocraft | glitch/scramble only (`--font-pixel`) | SIL OFL 1.1 (`LICENSE-Monocraft.txt`) |

**NeueBit & Mondwest** are bitmap typefaces by Pangram Pangram Foundry
(pangrampangram.com). The free "trial" weights cover personal projects,
portfolios and pitches. If this site ever becomes commercial, buy the full
license from Pangram Pangram. woff2 builds mirrored from a public project repo.

**Monocraft** — Minecraft-style pixel font by Idrees Hassan, SIL OFL, converted
from the v4.2.1 `.ttf` release. Source: https://github.com/IdreesInc/Monocraft
